# Lobia agent notes

- This is an installed Foundry VTT v13 system (`system.json`), not an npm project. Foundry loads `module/lobia.mjs` directly: `init` registers TypeDataModels and ApplicationV2 sheets; GM `ready` seeds world compendia and updates the bundled `lobia.pokemons` Actor pack. `module/data/` holds models/rules and cached catalogue registries, `module/documents/` handles mutations, `module/sheets/` + `templates/` are UI, `module/packs/` handles seeding/imports, and `tools/` contains offline scripts/tests.
- French UI strings live in `lang/fr.json`; mirror keys in `lang/en.json`. `tools/README.md` has extraction/test commands; `HANDOFF.md` is historical context, not a reliable source for current counts or versions.

## Verify changes

- From this directory, run a focused stubbed-Foundry check: `node tools/test/<name>.mjs` (e.g. `pokemonhpcheck.mjs` for Pokémon HP, `movepackcheck.mjs` for move imports). `node tools/test/loadtest.mjs` checks module loading/registration; ready-hook compendium warnings are expected in its incomplete stub. Template checks (`tplcheck.mjs`, `treecheck.mjs`, `derivedtpl.mjs`) load Handlebars from `~/Downloads/FoundryVTT-Node-13.351/`.
- For edited browser modules, use `node --check module/path.mjs`; direct Node imports of sheets/documents require Foundry globals. Workbook audits such as `node tools/test/pokedexsourcecheck.mjs [workbook.xlsx] [generated.mjs]` need the original workbook (default `~/Downloads/Pokedex Kanto.xlsx`) and `jar`.

## Data and runtime traps

- Regenerate workbook-derived `module/data/pokemon-*-data.mjs`, `module/data/pokemon-moves-data.mjs`, `module/packs/items-data.mjs`, and `module/packs/talents-data.mjs` via `tools/xlsx/`; do not edit them by hand. Pokédex extraction includes tree columns and **cell comments**; audit with `node tools/test/pokedexsourcecheck.mjs` after regenerating, and add new regional modules to `module/data/pokemon-pokedex.mjs`.
- Divighost's standalone workbook uses ten vertical role trees and eleven portraits; regenerate with `node tools/xlsx/extract-pokedex.mjs "$HOME/Downloads/Divighost.xlsx" module/data/pokemon-divighost-data.mjs --complete-only` and audit with `node tools/test/divighostsourcecheck.mjs`. Its Combat/Spectre template belongs in Spectre → LG; five member slots have independent trees.
- Seeders in `module/packs/` use version constants to propagate source changes to existing worlds; check each importer's merge/overwrite behavior before bumping a version or using `force`. `setupPokemonTemplates` refreshes bundled `lobia.pokemons` species templates, never captured world Actor copies. GM-owned compendia feed cached registries (skill/tree data falls back to bundled data only when that entire category is empty). Stable catalogue keys are persisted on Actors: renaming a document is safe, changing an assigned key or adding dots to keys is not.
- Foundry ObjectField updates **merge** maps: delete keys with flattened paths such as `"system.trees.<branch>.-=<node>"`, not by replacing the map. Each ApplicationV2 template PART needs one root element; numeric Handlebars path components use brackets (`{{system.tiers.[1]}}`).
- Never edit live Foundry LevelDB collections while the server runs. `tools/import-pokemon-pack.mjs --force` replaces the bundled pack; `tools/migrate-world-copy.mjs` only accepts an offline disposable world copy under `/tmp/opencode` and requires `--apply`.
